# winget manifests

Reference manifests for `Trimcraft.Trimcraft` in the
[winget community repository](https://github.com/microsoft/winget-pkgs), laid out as there
(`manifests/t/Trimcraft/Trimcraft/<version>/`). They are for the first, manual submission and as a
template; later versions are submitted by `.github/workflows/winget.yml` and are not copied back
here. See [docs/winget.md](../../docs/winget.md).

```powershell
winget validate --manifest packaging\winget\manifests\t\Trimcraft\Trimcraft\0.1.2
```
